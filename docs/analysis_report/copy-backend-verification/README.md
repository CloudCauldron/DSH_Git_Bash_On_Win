# Ordinary-copy release verification

The November 22–23, 2026 runs qualified the Windows executor that copies Git's flat `usr/bin` payload, patches the private MSYS image, and assigns each session its own junction view. Primary testing ran on Windows 11 x64 build 26200 with Windows Node 26.12.1 and DSH 0.2.2-rc.5, exercising Bash and Git across all three policies on both `ucrt64` Git 2.56.0.windows.4 and `mingw64` Git 2.55.0.windows.1.

| Question | Answer and evidence |
| --- | --- |
| What identifies the inputs? | The starting shipping commit, tool versions, and four raw locale-file hashes are recorded in the [baseline](evidence/baseline.md); [native qualification](evidence/native.md) records the official `mingw64` archive, PE checks, earlier DLL hashes, and independent reviews. |
| Can the ordinary account build and safely reuse the tree? | Both layouts used 11 resource junctions, with ordinary payload files holding independent identities and inherited cache permissions. Audits covered discovery through ambiguous paths, reparse targets, close failures, and cache admission. [Provisioning results](evidence/provisioning.md) |
| Does the executor retain confinement and lifetime semantics? | Tests covered live restricted tokens, confirmed waits, concurrent readers during rebuilds, cancellation, and source preservation, while actual Electron/ASAR runs verified child-console visibility and Settings rebuilds. [Executor cutover and audits](evidence/executor.md) |
| Does the packed plugin install, survive restart and uninstall? | Two independent packs matched byte for byte, Web and Desktop profile workers shared one generation, and a standalone process resolved purge dependencies inside the installed profile to remove the cache and lock after both hosts exited. [Release and audit](evidence/release.md) |
| Which deployment boundaries were tested separately? | A real Windows 10 host ran with Git and the cache on separate NTFS volumes, and a same-root offline PortableGit upgrade triggered an automatic rebuild even when the source MSYS stamp stayed unchanged. [Cross-volume test](evidence/release.md#cross-volume-operation) · [Offline upgrade](evidence/release.md#same-root-portablegit-upgrade) |
