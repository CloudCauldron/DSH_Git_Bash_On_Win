## Executor and publication audit

On Windows 11 build 26200, the first audit reproduced delayed timeout delivery during native workspace lookup, repeated recording of one close failure, and loss of an explicit environment key. Cache tests also exposed a growing owner marker during cold start, a missing payload masking a separate read failure, and a patched DLL too large for warm admission. The corrections in `de5ad38` passed the Windows suite (166/166) and browser suite (1/1). The short-path tests now require Windows to supply a different leaf spelling.

A second review traced the admitted workspace through the installed DSH confinement service. The executor now gives stock DSH a private policy copy with the canonical workspace. A test checks the incoming path and keeps the caller's policy frozen. Explicit blank settings use default Git discovery, including when the settings document is read-only. A worker published a different Git root while the parent process held the old pin, and a later build collected the released generation.

Both rounds passed typecheck and lint. The final Windows suite passed 166/166. The real mingw64 executor matrix passed 8/8 and packaged PowerShell, WinGet and GDB qualification passed 19/19. The supplied rc.5 Desktop executable and app.asar ran the audited package in an isolated profile. All three modes ran Git and reported no visible native child console. No new visible console was observed in 1,568 samples. Settings rebuild, navigation, normal exit and offline purge passed. The four locale implementation hashes and the release DLL hash matched the cutover record above.

## Settlement, paths and build outputs

The reviewed baseline was `66a2cf1`. From the provisioning revision `6b091b7` through that commit, Git reports 2,173 inserted and 8,020 deleted lines, a net reduction of 5,847. The native source gained 12 lines net. The import allowlist stayed the same. The package had five direct runtime dependencies and all 47 release-age exclusions matched the lockfile. A clean release build reproduced the tracked baseline.

Before correction, the controlled disposal tests observed two waits for an active child and two diagnostics for repeated unconfirmed settlement. The corrected tests require one active wait, one diagnostic and retention of the pin until positive settlement. A failed wait that precedes disposal can still succeed on retry. A corrupted source MSYS fixture previously wrote one ordinary payload before rejection. It now writes zero and retains the selected generation.

On Windows 11 build 26200, native Git Bash and Windows Node 26.12.1 passed typecheck, lint and the Windows suite (172/172). The mingw64 PE, native and executor suites passed 89/89. Long and 8.3 Bash entries produced the predicted namespace key on both Git layouts, including read-only and bound and agentless workspace-write. The packaged PowerShell, WinGet and GDB suite passed 19/19. The browser suite passed 1/1 with an unavailable compiler configured. An isolated missing-DSH control produced the two expected bootstrap failures and zero skips.

All 29 tracked build outputs matched between clean release and development builds and after the browser-only build. Two isolated native builds reproduced SHA-256 `0350d5533d5e887f47045ba1787db9dfaacbb9cffdbe5887feeb0e64a7ff75b7`. The four locale implementation files matched the baseline bytes. The packaged rc.5 Electron/ASAR Desktop used an isolated profile, ran all three modes, wrote version 1 to the marker and selector, rebuilt from Settings, navigated away, exited normally and released the cache for offline purge.
