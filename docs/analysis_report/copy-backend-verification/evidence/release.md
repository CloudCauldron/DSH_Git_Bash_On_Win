Two verified x64 PortableGit releases were extracted into disposable trees. All hosts exited before updating the selected tree from 2.56.0.windows.3 to 2.56.0.windows.4. The two MSYS DLLs had identical SHA-256 `2a89b7c31b323c42e2fb37900af087aeb27417694e630a210bc75b0369410bc7`. Copying all newer package files also changed that DLL’s timestamp.
